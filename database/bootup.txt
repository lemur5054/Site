🪟 After Windows Reinstall — Setup Checklist

Windows Updates

 Check for Windows Updates
 Install all optional updates as well
 Restart PC
 Check Windows Update again after restarting

Apps & Programs

 Install/update core apps and programs
 Install 7-Zip
 Install other required everyday programs
 Check for updates for all installed programs

Performance & Power

 Change Windows power mode to High Performance
 Turn off unnecessary Windows gaming features
 Xbox Game Bar
 Other unnecessary gaming/background features

Startup

 Open Startup Apps
 Disable all unnecessary startup programs
 Leave only essential/core startup apps enabled

Display

 Set monitor to its highest supported resolution
 Set monitor to its highest supported refresh rate

Network

 Set network DNS to the correct/preferred DNS
 Verify network speed after changing DNS
 Test Ethernet/Wi-Fi connection

Drivers

 Install/update GPU driver
 Install motherboard/chipset drivers
 Install network drivers
 Install audio drivers
 Check Device Manager for missing/incorrect drivers
